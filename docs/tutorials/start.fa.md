# از صفر تا اتصال

## پیش از شروع

> NetDesk سرور رایگان نمی‌سازد. برای اتصال، یک **پروفایل** (لینک vless، vmess، trojan، ss، hysteria2 یا tuic) یا یک **لینک اشتراک** لازم دارید که از سرور خودتان یا ارائه‌دهنده‌ی مورد اعتمادتان گرفته‌اید.

همه‌ی چیزی که لازم دارید در همین مخزن است. اول مخزن را دریافت کنید:

```powershell
git clone https://github.com/yourcreatorox7-lgtm/netdesk.git
```

## قدم ۱: هسته‌ی اتصال را نصب کنید

طبق آموزش **sing-box** هسته را از سورس داخل مخزن بسازید. فقط یک بار لازم است.

## قدم ۲: سرورهایتان را وارد کنید

- **سرور ویندوز خودتان (RDP):** آموزش «ساخت سرور خودم» را ببینید. پروفایل خودکار اضافه می‌شود.

- **لینک تکی:** در صفحه‌ی «پروفایل‌ها» لینک‌ها را بچسبانید.
- **اشتراک:** در صفحه‌ی «خانه»، بخش «اشتراک‌ها»، نشانی `https://` اشتراک را اضافه کنید و «به‌روزرسانی» را بزنید.

رمزها، UUIDها و نشانی اشتراک فقط در Windows Credential Manager ذخیره می‌شوند.

## قدم ۳: اتصال هوشمند

در صفحه‌ی «خانه» دکمه‌ی بزرگ **اتصال هوشمند** را بزنید. برنامه خودش این کارها را انجام می‌دهد:

1. دسترسی همه‌ی سرورها را هم‌زمان می‌سنجد.
2. سریع‌ترین‌ها را با یک درخواست واقعی از داخل تونل امتحان می‌کند.
3. اگر اتصال معمولی کار نکرد، دوباره با TLS fragment امتحان می‌کند.
4. بهترین را وصل می‌کند و پروکسی ویندوز را تنظیم می‌کند.
5. اگر اتصال قطع شد، خودش سراغ سرور بعدی می‌رود.

با «قطع اتصال» یا بستن برنامه، تنظیم پروکسی ویندوز به حالت قبل برمی‌گردد.

## کارهای خودکار

در صفحه‌ی «خانه» می‌توانید روشن کنید:

- **اتصال هنگام باز شدن برنامه**
- **به‌روزرسانی اشتراک‌ها هنگام باز شدن برنامه**
- **پروکسی سیستم** (برای مرورگرها و بیشتر برنامه‌های ویندوز)
- **جابه‌جایی خودکار** وقتی سرور قطع شود

## مشکلات رایج

- **«sing-box آماده نیست»:** آموزش sing-box را تا آخر انجام دهید، از جمله تأیید هشدارها.
- **«هیچ سروری در دسترس نیست»:** اول اینترنت خود دستگاه را در «عیب‌یابی» بررسی کنید.
- **«هیچ پروفایلی از داخل تونل پاسخ نداد»:** UUID یا رمز، SNI، تاریخ انقضای سرور و ساعت سیستم را بررسی کنید.
- **برنامه‌ای از پروکسی استفاده نمی‌کند:** بعضی برنامه‌ها پروکسی ویندوز را نادیده می‌گیرند. در تنظیمات خود آن برنامه، SOCKS5 یا HTTP را روی آدرسی که در صفحه‌ی خانه نشان داده شده بگذارید.
- **کلاینت پروکسی دیگری هم باز است:** بهتر است آن را ببندید. دو برنامه ممکن است تنظیم پروکسی ویندوز را روی هم بنویسند.
