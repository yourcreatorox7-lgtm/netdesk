# دستیار هوش مصنوعی

صفحه‌ی «دستیار هوشمند» با یک مدل **محلی** روی دستگاه خودتان کار می‌کند (Ollama). هیچ داده‌ای از دستگاه بیرون نمی‌رود و کلید API هم لازم نیست.

## نصب

```powershell
winget install Ollama.Ollama
```

برنامه‌ی Ollama را باز کنید. بعد در صفحه‌ی «دستیار هوشمند» یکی از مدل‌های پیشنهادی را دانلود کنید. حجم هر مدل چند گیگابایت است.

## چه کارهایی می‌کند

- به سؤال‌هایتان درباره‌ی برنامه و خطاها جواب می‌دهد.
- می‌تواند این کارها را **پیشنهاد** بدهد: اتصال هوشمند، قطع اتصال، به‌روزرسانی اشتراک‌ها، تست شبکه و باز کردن صفحه‌ها.
- با روشن کردن **خلبان خودکار**، همین کارها را خودش انجام می‌دهد، نتیجه را می‌بیند و قدم بعدی را انتخاب می‌کند (حداکثر ۳ قدم برای هر درخواست).

## چه کارهایی نمی‌تواند بکند

- فرمان دلخواه اجرا کند یا فایل‌ها را تغییر دهد.
- ابزارهای پرخطر را اجرا کند یا هشدارها را به‌جای شما تأیید کند.
- رمز، UUID، نشانی سرور، نام پروفایل یا لینک اشتراک شما را ببیند.

> مدل‌های کوچک گاهی اشتباه می‌کنند. به حرفشان بدون بررسی تکیه نکنید.

## استفاده از هوش مصنوعی دیگر

دکمه‌ی **کپی گزارش بدون اطلاعات حساس** متنی آماده می‌سازد که می‌توانید در هر دستیار دیگری بچسبانید. پیش از فرستادن، یک بار خودتان آن را بخوانید.
