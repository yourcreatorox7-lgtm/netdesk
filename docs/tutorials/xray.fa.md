# Xray-core

سازنده: تیم Project X (XTLS) · لایسنس: MPL-2.0 · ریسک: متوسط · سورس: پوشه‌ی `vendor/Xray-core`

هسته‌ی دوم NetDesk. «اتصال هوشمند» برای همه‌ی پروفایل‌ها از sing-box استفاده می‌کند، **به‌جز پروفایل‌های xhttp** که sing-box اصلاً پشتیبانی نمی‌کند. برای آن‌ها NetDesk خودش کانفیگ Xray می‌سازد و اجرا می‌کند. اگر Xray ثبت نشده باشد، این پروفایل‌ها با پیام روشن کنار گذاشته می‌شوند.

## استفاده‌ی خودکار برای xhttp

1. Xray را مثل پایین بسازید.
2. «هسته و ابزارها» ← کارت **Xray-core** ← **پیدا کردن خودکار** ← **ثبت مسیر و هش** ← تأیید هشدارها. آرگومان لازم نیست.
3. «اتصال هوشمند» را بزنید. پروفایل‌های xhttp هم در تست می‌آیند.

نکته: Xray جدید `allowInsecure` را حذف کرده است. اگر سرور گواهی خودامضا دارد، لینک باید `pcs` (هش SHA-256 گواهی) یا `vcn` داشته باشد.

## ساخت از سورس

```powershell
winget install GoLang.Go
```

```powershell
powershell -ExecutionPolicy Bypass -File scripts\build-tool.ps1 xray
```

خروجی: `%LOCALAPPDATA%\NetDesk\bin\xray.exe`

## کانفیگ دستی (اختیاری)

فایل `config.json` خود را در پوشه‌ای **بیرون از مخزن** بسازید تا رمزهایتان در گیت نرود. نمونه‌ی ورودی امن (فقط همین دستگاه):

```json
{
  "inbounds": [
    { "listen": "127.0.0.1", "port": 10810, "protocol": "socks" }
  ],
  "outbounds": [ { "protocol": "freedom" } ]
}
```

بخش `outbounds` را با مشخصات سرور خودتان جایگزین کنید.

> `listen` را روی `0.0.0.0` نگذارید. در آن صورت همه‌ی دستگاه‌های شبکه می‌توانند از پروکسی شما استفاده کنند.

## اجرا در NetDesk

1. «ابزارهای پرخطر» ← کارت **Xray-core** ← **پیدا کردن خودکار**.
2. آرگومان‌ها: `run -c C:\path\to\config.json`
3. ثبت مسیر و هش، تأیید هشدارها، و **اجرا**.
4. برنامه‌ی دلخواه را روی `127.0.0.1:10810` (SOCKS5) تنظیم کنید.
