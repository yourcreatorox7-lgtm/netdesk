# sing-box (هسته‌ی اتصال)

سازنده: nekohasekai (پروژه‌ی SagerNet) · لایسنس: GPL-3.0-or-later · ریسک: متوسط · سورس: پوشه‌ی `vendor/sing-box`

برای «اتصال هوشمند» و دکمه‌ی «اتصال» پروفایل‌ها لازم است.

## پیش‌نیاز

زبان Go را نصب کنید و بعد یک ترمینال تازه باز کنید:

```powershell
winget install GoLang.Go
```

## ساخت از سورس

در پوشه‌ی مخزن:

```powershell
powershell -ExecutionPolicy Bypass -File scripts\build-tool.ps1 sing-box
```

- بار اول چند صد مگابایت وابستگی دانلود می‌شود. اگر اینترنت قطع شود، اسکریپت خودش دوباره تلاش می‌کند. دوباره اجرا کردن هم از همان‌جا ادامه می‌دهد.
- فایل ساخته‌شده در `%LOCALAPPDATA%\NetDesk\bin\sing-box.exe` قرار می‌گیرد و اسکریپت هش SHA-256 آن را نشان می‌دهد.
- اگر پیام نسخه‌ی Go دیدید، Go را به‌روز کنید.

> درایور WinDivert در این کپی نیست. اسکریپت با گزینه‌ی رسمی `with_external_windivert` می‌سازد که درایور را داخل برنامه نمی‌گذارد. NetDesk به آن نیازی ندارد، چون فقط پروکسی محلی می‌سازد.

## ثبت در NetDesk

1. صفحه‌ی «ابزارهای پرخطر» ← کارت **sing-box** ← **پیدا کردن خودکار**.
2. **ثبت مسیر و هش** را بزنید. هش باید همان هشی باشد که اسکریپت نشان داد.
3. **خواندن و تأیید هشدارها**: همه را تیک بزنید و عبارت تأیید را تایپ کنید.

اگر فایل را دوباره بسازید، هش عوض می‌شود و باید دوباره ثبت و تأیید کنید.

## اتصال

به صفحه‌ی «خانه» بروید و **اتصال هوشمند** را بزنید.

## حذف

فایل `sing-box.exe` را از `%LOCALAPPDATA%\NetDesk\bin` پاک کنید و در کارت ابزار «فراموش کن» را بزنید.
